# easynet v0.3.0

江西农业大学校园网自动认证工具，Windows 10/11 x64。

## 本次变化

### 新增

- **自动连接校园 Wi-Fi**：左下角新增开关，**默认关闭**、状态持久保存。开启后如果当前没连着 `JXAU-Stu`，守护会自动连回来
  - 系统里没有该网络的配置时（例如刚「忘记」过），会自动创建一份开放网络配置再连接
  - 不会开启或关闭无线网卡；Wi-Fi 硬件关闭时只记日志，不强行改系统设置

### 修复

- **改名后界面闪退 / 守护误报「已在运行」**：`epo` 改名时把界面与守护的互斥体都替换成了同名 `Local\easynet`，导致界面自己占住守护的锁
- **关闭守护开关会连带关闭界面**：托盘退出回调被守护被动退出复用，停止守护时误关了窗口
- **「忘记网络」后无法自动连接**：`netsh wlan connect` 在配置不存在时退出码仍是 0，旧逻辑误判为成功；现在改为轮询验证是否真的连上，未连上再创建配置重试

## 下载

| 包 | 适合谁 | 怎么卸载 |
|---|---|---|
| `easynet-windows-x64.zip`（绿色版） | 不想安装、想放任意目录或 U 盘 | 运行目录里的 `uninstall.bat` |
| `easynet-setup-*.exe`（安装版） | 想从「设置 → 应用」正常卸载 | 应用列表卸载，或运行 `unins000.exe` |

数据保存在 `%LOCALAPPDATA%\easynet`，升级时覆盖 exe 不会丢配置；运行日志写在程序目录的 `log` 文件夹。

## 快速开始

1. 解压 / 安装后双击 `easynet.exe`
2. 「账号」页填写学号、密码、运营商线路并保存
3. 概览页确认「守护」开关已打开（默认打开，关掉界面后依然保持）
4. 需要开机自动重连，打开左下角「开机自启」
5. 想让软件在没连校园网时自动连回来，打开左下角「自动连接 Wi-Fi」（默认关闭）

## 从旧版本升级

- 数据目录与程序名已是 `easynet`，从 v0.1.0 升级需要重新填写一次账号
- 旧的 `epo-daemon` 自启项不会自动迁移，重新开关一次「开机自启」即可

## 已知限制

- 仅 Windows 10/11 x64，需要系统 WebView2
- 无代码签名，SmartScreen 会提示「未知发布者」
- 无自动更新，升级需手动覆盖 exe
- 仅适配江西农业大学，不支持其他学校

## 校验

`checksums.txt` 内含 `easynet.exe` 的 SHA256；压缩包自身的 SHA256 在 `.sha256` 附件中。
