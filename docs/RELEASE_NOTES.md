# easynet v0.6.6.1

这次修的是更新器本身：安全软件拦截改名时，旧版本可能被改成 `.old` / `.probe` 的名字，主程序位置空掉，更新完反而打不开。

## 修复

- **更新改为退出后替换**：下载与 SHA256 校验通过后，新版本先写成同目录的 `.easynet.exe.new`，程序退出后由脚本换入并启动；任何一步失败都保留旧版本，不再在运行中改主程序
- **启动自动恢复残留**：主程序缺失时，依次用 `.easynet.exe.old`、`.easynet.exe.old.probe` 恢复，已中招的机器升级后可直接修复
- **清理残留更彻底**：成功启动后同时清理 `.old` 与 `.probe`，不再留下占空间的旧文件

## 安装

| 包 | 适合谁 | 怎么卸载 |
|---|---|---|
| `easynet-setup-0.6.6.1.exe` | 大多数用户：标准安装，带「程序和功能」卸载项 | 设置 → 应用 → easynet → 卸载 |
| `easynet-windows-x64.zip` | 想直接运行、不写安装记录的用户 | 解压到哪里用到哪里，删除文件夹即卸载（绿色版） |
| `easynet.exe` | 单文件直接运行 | 删除文件即卸载 |

> 已在 0.6.6 更新失败的机器：把 `.easynet.exe.old.probe`（或 `.easynet.exe.old`）重命名回 `easynet.exe` 启动旧版，再手动下载 0.6.6.1 覆盖。0.6.5 / 0.6.6 自带的更新器有此缺陷，不建议再用它自动更新。

> Windows 10 / 11 x64。运行单文件或绿色版前，如 SmartScreen 出现「已保护你的电脑」，点击「更多信息」→「仍要运行」。
