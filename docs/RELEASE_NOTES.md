# epo v0.1.0

江西农业大学校园网自动认证工具，Windows 10/11 x64。

## 下载

下载 `epo-windows-x64.zip`，解压后三个 exe 必须放在同一目录：

- `epo-gui.exe` — 图形界面（推荐）
- `epo-daemon.exe` — 守护进程 + 系统托盘（开机自启指向它）
- `epo.exe` — 命令行

## 亮点

- **掉线自动重连**：真机实测 4.1 秒恢复在线
- **关闭窗口不影响**：守护是独立进程，界面只是外壳
- **原生窗口**：无边框自绘标题栏，深色 / 浅色双主题
- **凭据安全**：Windows DPAPI 加密，仅本机本账户可解密
- **防劫持**：首次登录记录网关 MAC，之后变化即拒绝自动登录
- **无需管理员**：开机自启写 HKCU\Run

## 快速开始

1. 解压，双击 `epo-gui.exe`
2. 「账号」页填写学号、密码、运营商线路并保存
3. 概览页点「启动守护」
4. 需要开机自动重连，打开左下角「开机自启」

## 已知限制

- 仅 Windows 10/11 x64，需要系统 WebView2
- 无代码签名，SmartScreen 会提示「未知发布者」
- 无自动更新，升级需手动覆盖 exe
- 仅适配江西农业大学，不支持其他学校

## 校验

`checksums.txt` 内含三个 exe 的 SHA256；压缩包自身的 SHA256 在 `.sha256` 附件中。
