# easynet v0.5.1

江西农业大学校园网自动认证工具，Windows 10/11 x64。

## 本次变化

### 界面

- **概览信息卡视觉精修**：六张信息卡（Wi-Fi / 本机 IP / 默认网关 / 网关 MAC / 本机 MAC / 凭据信任）升级为——
  - 每卡配语义主题色图标（Wi-Fi 蓝、网络参数青、安全项黄、凭据绿）
  - 数值加大加粗高亮，SSID 主色显示，IP/网关/MAC 等宽字体
  - hover 时卡片上浮 + 阴影 + 顶部渐变细线点亮
  - 凭据与信任状态改为双药丸徽章（绿=正常，红=缺失），深浅色主题自适应

### 修复

- **关于页版本号显示为 `v[object Promise]`**：版本接口为异步绑定，未等待完成即拼接字符串；现正确显示 `v0.5.1`

## 说明

- 本次为 v0.5.0 发布后的增量改进，跨校区认证、校区滑条、分校区账号、验证码 OCR 等能力与 v0.5.0 一致
- 下一版本计划：前端组件化（element-plus 路线，0.6.0 立项）

## 下载

| 包 | 适合谁 | 怎么卸载 |
|---|---|---|
| `easynet-setup-0.5.1.exe` | 大多数用户：标准安装，带「程序和功能」卸载项 | 设置 → 应用 → easynet → 卸载 |
| `easynet-windows-x64.zip` | 想直接运行、不写安装记录的用户 | 解压到哪里用到哪里，删除文件夹即卸载（绿色版） |
| `easynet.exe` | 单文件直接运行 | 删除文件即卸载 |

> Windows 10 / 11 x64。运行单文件或绿色版前，如 SmartScreen 出现「已保护你的电脑」，点击「更多信息」→「仍要运行」。
