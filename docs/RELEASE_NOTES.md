# easynet v0.6.2

本次修复双校区用户的一个高影响问题：在界面选择本部后，后台守护仍按东区回连，开机后连不上 `JXAU`，只能手动连接并点登录。

## 修复

- **校区偏好不生效**：守护此前读取的是旧配置文件名，读不到就退回内置默认值（东区），所以无论界面怎么切校区，守护始终只连 `JXAU-Stu`。现在界面与守护读取同一份配置，选择本部后开机即可自动连接 `JXAU` / `CMCC-JXAU`
- **切换后立即生效**：守护每轮自动回连前重新读取校区偏好，在界面切换校区后不用重启守护
- **日志更直观**：「守护启动」改为显示偏好校区与回连目标（例如 `偏好校区 本部 · 回连目标 JXAU,CMCC-JXAU`），不再只显示配置里的东区字段

## 说明

账号仍按校区分别保存：东区与本部各有一份。切到本部后，如果提示「本部校区尚未保存账号」，在账号页的本部分组保存一次即可。

## 安装

| 包 | 适合谁 | 怎么卸载 |
|---|---|---|
| `easynet-setup-0.6.2.exe` | 大多数用户：标准安装，带「程序和功能」卸载项 | 设置 → 应用 → easynet → 卸载 |
| `easynet-windows-x64.zip` | 想直接运行、不写安装记录的用户 | 解压到哪里用到哪里，删除文件夹即卸载（绿色版） |
| `easynet.exe` | 单文件直接运行 | 删除文件即卸载 |

> Windows 10 / 11 x64。运行单文件或绿色版前，如 SmartScreen 出现「已保护你的电脑」，点击「更多信息」→「仍要运行」。
