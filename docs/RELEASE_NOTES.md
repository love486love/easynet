# easynet v0.2.0

江西农业大学校园网自动认证工具，Windows 10/11 x64。

## 本次变化

- **改名**：项目从 `epo` 更名为 `easynet`，加入江农元素的图标（麦穗 + 齿轮）
- **单文件发行**：界面与守护合并为同一个 `easynet.exe`，发行包从 20.9 MB 降到 9.68 MB，下载包约 4–5 MB
- **去掉命令行程序**：普通用户只需要双击 exe，不再附带用不上的 CLI
- **守护改成像开机自启一样的开关**：默认开启、状态持久保存，关掉界面或从托盘退出后重新打开仍是开启
- **保存账号后自动启动守护**，切换账号时守护自动用新账号重启
- **WebView2 缺失提示**改为直接引导安装运行时

## 下载

| 包 | 适合谁 | 怎么卸载 |
|---|---|---|
| `easynet-windows-x64.zip`（绿色版） | 不想安装、想放任意目录或 U 盘 | 运行目录里的 `uninstall.bat` |
| `easynet-setup-*.exe`（安装版） | 想从「设置 → 应用」正常卸载 | 应用列表卸载，或运行 `unins000.exe` |

数据保存在 `%LOCALAPPDATA%\easynet`，升级时覆盖 exe 不会丢配置；运行日志写在程序目录的 `log` 文件夹。

## 快速开始

1. 解压 / 安装后双击 `easynet.exe`
2. 「账号」页填写学号、密码、运营商线路并保存
3. 概览页确认「守护」开关已打开（默认打开，关掉界面后依然保持）
4. 需要开机自动重连，打开左下角「开机自启」

## 从 v0.1.0 升级

- 程序名、数据目录、开机自启项都已改名，**需要重新填写一次账号**
- 旧的 `epo-daemon` 自启项不会自动迁移，重新开关一次「开机自启」即可

## 已知限制

- 仅 Windows 10/11 x64，需要系统 WebView2
- 无代码签名，SmartScreen 会提示「未知发布者」
- 无自动更新，升级需手动覆盖 exe
- 仅适配江西农业大学，不支持其他学校

## 校验

`checksums.txt` 内含 `easynet.exe` 的 SHA256；压缩包自身的 SHA256 在 `.sha256` 附件中。
