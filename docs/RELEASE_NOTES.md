# easynet v0.4.6.2

江西农业大学校园网自动认证工具，Windows 10/11 x64。

## 本次变化

### 修复

- **自动更新可能把程序文件替换失败，导致程序无法再启动**：下载、校验都成功后，最后把新文件换到 `easynet.exe` 这一步，如果被安全软件瞬间锁住就会失败，旧文件已改名、新文件没换进去，目标位置直接空掉
  - 现在替换失败会自动重试（每次失败间隔 1 秒，共 3 次），改名步骤本身也有短重试，覆盖安全软件的扫描锁窗口
  - 万一上次更新已经留下「程序文件缺失」的残留，下一次更新会先自动把旧文件恢复回原位再继续
  - 全部重试仍失败时，保证旧版本仍可正常使用，并把现场状态写进日志

### 日志详细化

- **界面进程现在也写日志**：此前只有后台守护写日志，检查更新、下载、校验、替换这些动作全部没有记录，出了问题无从查起
- 全链路落盘：检查更新（当前 / 最新版本）、获取下载地址、下载方式与耗时平均速度、SHA256 校验结果、替换每一步的结果与失败原因、目录现场状态
- 认证链路补全：安全校验未通过、发起登录（门户 / 账号脱敏 / userip / SSID）、网关返回码、探针从失败恢复、探针无法判定的首次记录、掉线时的判定依据
- 界面启动、保存账号、守护启停、开机自启设置均记录，排查时一个日志文件即可看全

### 说明

- 自动更新完成后照旧自动重启，无需手动操作
- 其余功能与 v0.4.6.1 一致
- 建议所有使用自动更新的用户更新

## 下载

| 包 | 适合谁 | 怎么卸载 |
|---|---|---|
| `easynet-windows-x64.zip`（绿色版） | 不想安装、想放任意目录或 U 盘 | 运行目录里的 `uninstall.bat` |
| `easynet-setup-*.exe`（安装版） | 想从「设置 → 应用」正常卸载 | 应用列表卸载，或运行 `unins000.exe` |

数据保存在 `%LOCALAPPDATA%\easynet`，升级时覆盖 exe 不会丢配置；运行日志写在程序目录的 `log` 文件夹。

## 快速开始

1. 解压 / 安装后双击 `easynet.exe`
2. 「账号」页填写学号、密码、运营商线路并保存
3. 概览页确认「守护」开关已打开（默认打开，关掉界面后依然保持）
4. 需要开机自动重连，到「设置」页打开「开机自启」
5. 想让软件在没连校园网时自动连回来，到「设置」页打开「自动连接校园 Wi-Fi」（默认关闭）

## 已知限制

- 仅 Windows 10/11 x64，需要系统 WebView2
- 无代码签名，SmartScreen 会提示「未知发布者」
- 仅适配江西农业大学，不支持其他学校

## 校验

`checksums.txt` 内含 `easynet.exe` 与安装包的 SHA256；压缩包自身的 SHA256 在 `.sha256` 附件中。绿色版与安装版的自动更新都会核对，校验不通过不会替换文件或启动安装。
