# easynet v0.6.0

本次更新以界面重构为主：日志页改为可筛选的事件流，账号页改为卡片式管理，整体加入毛玻璃质感与自定义光标。

## 界面

- **运行日志**：日志按「时间 / 级别 / 消息」三段式展示，附加参数以灰色小字跟随；支持「全部 / 警告 / 错误」筛选、关键字搜索与自动滚动开关。向上翻阅历史时不会被新日志打断
- **账号管理**：账号改为卡片样式，按运营商显示彩色头像与所在校区；选中的账号左侧有强调条；分组头部改为图标、标题与计数药丸；存储说明折叠收起
- **校区标识**：东区使用小黑猪剪影，本部使用校门剪影
- **毛玻璃外观**：侧栏、标题栏与各面板采用半透明模糊层，背景带柔和光斑
- **鼠标光晕**：跟随指针的淡色柔光，仅在右侧内容区显示，靠近边缘自然淡出
- **自定义光标**：统一为圆润箭头，移到可点击区域时描边变为主题蓝

## 体验

- 错误提示统一为自动消失的弹窗，同一错误短时间内不会重复弹出
- 网络状态卡只保留状态与操作，长错误不再撑高卡片
- 输入框获得焦点时显示柔和外圈

## 工程

- 前端迁移到 Vite + TypeScript 构建，产物体积较上一版减少约 23%
- 仓库新增前端类型检查与产物一致性校验，随 CI 自动执行

## 安装

| 包 | 适合谁 | 怎么卸载 |
|---|---|---|
| `easynet-setup-0.6.0.exe` | 大多数用户：标准安装，带「程序和功能」卸载项 | 设置 → 应用 → easynet → 卸载 |
| `easynet-windows-x64.zip` | 想直接运行、不写安装记录的用户 | 解压到哪里用到哪里，删除文件夹即卸载（绿色版） |
| `easynet.exe` | 单文件直接运行 | 删除文件即卸载 |

> Windows 10 / 11 x64。运行单文件或绿色版前，如 SmartScreen 出现「已保护你的电脑」，点击「更多信息」→「仍要运行」。
