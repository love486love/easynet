# easynet v0.6.4

这次把「关于」页面收拾了一遍，更新说明终于能正常阅读了。

## 新增

- **更新说明格式化显示**：标题、列表、加粗、表格按排版渲染，不再显示 `##` 和 `**` 这样的原始标记
- **Star（收藏）按钮**：关于页新增 GitHub 入口，能读到数据时显示当前 Star 数；离线或接口限流时只保留按钮，不影响点击跳转
- **更新内容区域加高**：一次能看到更多条目，超出部分在框内滚动

## 说明

- Star 数来自 GitHub 公开接口，仅在联网且未触发限流时显示
- 更新检查、自动更新与登录逻辑均未改动

## 安装

| 包 | 适合谁 | 怎么卸载 |
|---|---|---|
| `easynet-setup-0.6.4.exe` | 大多数用户：标准安装，带「程序和功能」卸载项 | 设置 → 应用 → easynet → 卸载 |
| `easynet-windows-x64.zip` | 想直接运行、不写安装记录的用户 | 解压到哪里用到哪里，删除文件夹即卸载（绿色版） |
| `easynet.exe` | 单文件直接运行 | 删除文件即卸载 |

> Windows 10 / 11 x64。运行单文件或绿色版前，如 SmartScreen 出现「已保护你的电脑」，点击「更多信息」→「仍要运行」。
