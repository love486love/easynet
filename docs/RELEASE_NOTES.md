# easynet v0.6.3

本次修复双校区用户的一个高影响问题：在本部使用时，程序会拿东区门户地址发起认证，导致登录必然失败且反复重试。

## 修复

- **校区彻底隔离**：门户地址、认证协议与 Wi-Fi 名称都按界面选择的校区锁定。选本部只用本部门户，选东区只用东区门户，不再自动切换到另一个校区
- **本部登录自动补齐参数**：开机时网络尚未就绪、探测拿不到门户跳转参数的情况下，会直连门户补抓，不再直接放弃
- **失败提示可操作**：仍拿不到参数时，改为提示先用浏览器打开任意网页触发认证页，不再无声循环重试
- **切换立即生效**：在界面切换校区后，后台守护下一轮就按新选择执行，无需重启

## 说明

账号仍按校区分别保存：东区与本部各有一份。切到本部后，如果提示「本部校区尚未保存账号」，在账号页的本部分组保存一次即可。

## 安装

| 包 | 适合谁 | 怎么卸载 |
|---|---|---|
| `easynet-setup-0.6.3.exe` | 大多数用户：标准安装，带「程序和功能」卸载项 | 设置 → 应用 → easynet → 卸载 |
| `easynet-windows-x64.zip` | 想直接运行、不写安装记录的用户 | 解压到哪里用到哪里，删除文件夹即卸载（绿色版） |
| `easynet.exe` | 单文件直接运行 | 删除文件即卸载 |

> Windows 10 / 11 x64。运行单文件或绿色版前，如 SmartScreen 出现「已保护你的电脑」，点击「更多信息」→「仍要运行」。
