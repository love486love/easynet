# easynet v0.5.2

江西农业大学校园网自动认证工具，Windows 10/11 x64。

## 本次变化

### 修复与可靠性

- **自动更新防拦截（针对 360 等安全软件的自我保护）**：
  - **替换前预检**：正式替换前先做一次无害的「移走→移回」试探；被安全软件拦截时**当前版本原封不动**，从机制上杜绝「更新失败后程序文件凭空消失、再也起不来」的事故
  - **被拦截立即停止**：识别 `Access is denied` 后不再盲目重试，界面直接给出明确指引（含程序目录路径，提示加入安全软件信任区）
  - **一键完成脚本**：替换失败时自动生成同目录 `update-helper.bat`——双击并在安全软件弹窗中点「允许」即可完成更新并自动启动新版本；恢复失败的日志会明确标注「程序文件当前缺失」及补救步骤

## 说明

- 建议配合一次手动更新到本版本：0.5.1 及更早版本的更新器不含本防护（受「先装保护后受益」限制），从 0.5.2 起后续自动更新全程受保护
- 跨校区认证、校区开关、分校区账号、验证码 OCR 等能力与 v0.5.0 一致
