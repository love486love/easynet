# easynet v0.6.5

自动更新成功后，安装目录会留下一个 `.easynet.exe.old` 旧版本备份。这次让程序在下次启动时自动清理它。

## 修复

- **清理旧版本备份**：Windows 无法覆盖正在运行的程序文件，更新时必须先把旧文件改名再写入新文件；新版本启动后会自动删除这个备份
- **失败不影响启动**：文件被安全软件短暂占用时，后台延迟重试一次，不会卡住启动
- **保护唯一副本**：如果主程序文件缺失，备份会被保留而不是删除，避免把唯一的可执行文件删掉

## 说明

已经存在的 `.easynet.exe.old` 不用手动处理，升级到本版本后启动一次即可清掉；也可以在主程序未运行时直接删除。

## 安装

| 包 | 适合谁 | 怎么卸载 |
|---|---|---|
| `easynet-setup-0.6.5.exe` | 大多数用户：标准安装，带「程序和功能」卸载项 | 设置 → 应用 → easynet → 卸载 |
| `easynet-windows-x64.zip` | 想直接运行、不写安装记录的用户 | 解压到哪里用到哪里，删除文件夹即卸载（绿色版） |
| `easynet.exe` | 单文件直接运行 | 删除文件即卸载 |

> Windows 10 / 11 x64。运行单文件或绿色版前，如 SmartScreen 出现「已保护你的电脑」，点击「更多信息」→「仍要运行」。
