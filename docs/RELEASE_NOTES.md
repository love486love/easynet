# easynet v0.6.6

这次修了校区切换的一个 bug，并让守护在几种"再怎么重试也没用"的情况下学会停下来。

## 修复

- **校区设定不再被覆盖**：概览页的校区滑条只表示你设定的校区；实际连着的网络单独显示，两者不一致时会提示，而不是把滑条改到当前网络
- **不在设定校区时不代登录**：连着手机热点或另一校区时，守护只观察不登录，不消耗失败次数与登录配额

## 改进

- **限时断网不再硬撞**：网关提示"不在上网时段"时，守护静默 30 分钟，期间只探测不登录，到点自动再试；想立刻试一次可以点「立即登录」
- **密码错误/账号锁定停止自动重试**：避免反复尝试加重锁定，界面会提示原因并给出「去修改」入口；保存新账号后自动恢复
- **并发登录延长退避**：同一账号在别处在线时逐步拉长重试间隔，最多 10 分钟，不再频繁互踢
- **检查更新可直连**：设置页新增「更新时直连」开关，系统代理未启动或超时时可绕开代理连接 GitHub
- **更新失败提示更清楚**：检查更新失败时会区分"代理未启动"和"连接超时"，并直接提示可开启「更新时直连」，不再只有一句"无法连接 GitHub"

## 安装

| 包 | 适合谁 | 怎么卸载 |
|---|---|---|
| `easynet-setup-0.6.6.exe` | 大多数用户：标准安装，带「程序和功能」卸载项 | 设置 → 应用 → easynet → 卸载 |
| `easynet-windows-x64.zip` | 想直接运行、不写安装记录的用户 | 解压到哪里用到哪里，删除文件夹即卸载（绿色版） |
| `easynet.exe` | 单文件直接运行 | 删除文件即卸载 |

> Windows 10 / 11 x64。运行单文件或绿色版前，如 SmartScreen 出现「已保护你的电脑」，点击「更多信息」→「仍要运行」。
