# easynet v0.5.0

江西农业大学校园网自动认证工具，Windows 10/11 x64。

## 本次变化

### 新功能

- **跨校区多门户支持（本部）**：连接本部校区校园网（`JXAU`）时自动识别锐捷 ePortal 门户（`10.255.240.8`）并完成登录，与东区 Dr.COM 门户按重定向指纹自动切换，无需任何手动设置
- **概览页校区大滑条**：一键选择自动连接的校区（东区 `JXAU-Stu` / 本部 `JXAU`），滑条实时显示当前实际连上的校区，拖动后立即发起连接并由守护自动登录；未连校园网时按滑条记忆的偏好自动回连
- **账号按校区分列表**：账号页改为「东区账号」「本部账号」两列，连哪个校区就用哪边的账号，守护按探测到的门户自动选用对应校区的账号（东区账号只能连东区、本部账号只能连本部）；旧版本保存的账号自动归入东区列表
- **目标校园网支持多 SSID**：`JXAU-Stu`（东区）与 `JXAU`（本部）均为可自动登录的目标网络，判离线逻辑一致（连上目标校园网 3 次探不通即发起登录）

### 说明

- **本部登录协议全链路实机打通**：AC 拦截是「200 + 511 字节 JS 跳转页」而非 302，探针自动从正文提取跳转参数（rawquery / 门户指纹）；登录前置门户 session，4 位数字验证码内置 OCR 自动识别（识别不出自动换图，绝不猜），识别成功的验证码会存入本地模板库自举，覆盖全部数字字形
- 登录参数取自劫持页跳转的完整 query string 并按实测 HAR 逐字段复刻（含双重 URL 编码），登录成功后自动完成跳转确认
- 旧版本配置升级后自动补齐跨校区默认值，无需重新配置

## 下载

| 包 | 适合谁 | 怎么卸载 |
|---|---|---|
| `easynet-windows-x64.zip`（绿色版） | 不想安装、想放任意目录或 U 盘 | 运行目录里的 `uninstall.bat` |
| `easynet-setup-*.exe`（安装版） | 想从「设置 → 应用」正常卸载 | 应用列表卸载，或运行 `unins000.exe` |

数据保存在 `%LOCALAPPDATA%\easynet`，升级时覆盖 exe 不会丢配置；运行日志写在程序目录的 `log` 文件夹。

## 快速开始

1. 解压 / 安装后双击 `easynet.exe`
2. 「账号」页填写学号、密码、运营商线路并保存
3. 概览页确认「守护」开关已打开（默认打开，关掉界面后依然保持）
4. 需要开机自动重连，到「设置」页打开「开机自启」
5. 想让软件在没连校园网时自动连回来，到「设置」页打开「自动连接校园 Wi-Fi」（默认关闭）

## 已知限制

- 仅 Windows 10/11 x64，需要系统 WebView2
- 无代码签名，SmartScreen 会提示「未知发布者」
- 仅适配江西农业大学，不支持其他学校
- 门户登录接口为校内 HTTP，密码经校内链路明文传输属门户协议限制，客户端无法规避，仅在可信校园网环境下使用

## 校验

`checksums.txt` 内含 `easynet.exe` 与安装包的 SHA256；压缩包自身的 SHA256 在 `.sha256` 附件中。绿色版与安装版的自动更新都会核对，校验不通过不会替换文件或启动安装。
