# easynet v0.6.1

本次更新集中在本部（锐捷 ePortal）验证码：识别模板补齐到 0–9 全覆盖，自动识别连续失败时不再直接报错，而是让你手动输入。

## 验证码

- **模板补全**：内置样本补齐了 1 与 7 两个字形的缺失，0–9 数字全部覆盖，日常登录基本不会再出现「换了 4 张图都认不出」
- **人工输入兜底**：自动识别连续 4 张都失败时，程序会弹出验证码图片和输入框，填入图中 4 位数字即可继续登录，不必重新发起
- **识别自举**：每次登录成功后，这一轮的「验证码图 + 正确答案」会存入本地模板库，相同字形下次直接识别

## 文档

- 技术设计文档同步到当前版本：补充双校区适用范围、Vite + TypeScript 前端技术栈、验证码兜底路径

## 安装

| 包 | 适合谁 | 怎么卸载 |
|---|---|---|
| `easynet-setup-0.6.1.exe` | 大多数用户：标准安装，带「程序和功能」卸载项 | 设置 → 应用 → easynet → 卸载 |
| `easynet-windows-x64.zip` | 想直接运行、不写安装记录的用户 | 解压到哪里用到哪里，删除文件夹即卸载（绿色版） |
| `easynet.exe` | 单文件直接运行 | 删除文件即卸载 |

> Windows 10 / 11 x64。运行单文件或绿色版前，如 SmartScreen 出现「已保护你的电脑」，点击「更多信息」→「仍要运行」。
