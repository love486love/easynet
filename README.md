# epo

校园网门户自动认证客户端（Windows 10/11 x64）。

连上校园 Wi-Fi 后自动完成 Dr.COM ePortal 网页认证，无需再打开浏览器输入账号密码。

> 当前状态：**设计阶段**。协议与在线判定已通过真实抓包与断网/联网双向实测验证，代码尚未开始。

## 特性（规划）

- 连网自动认证、断线自动恢复
- 常驻守护进程（含托盘），内存占用目标 < 40 MB
- 图形界面按需启动，关闭即释放
- 凭据使用 Windows DPAPI 加密，仅本机本账户可解密
- 探针只读响应头，单次流量 ≤ 10 KB
